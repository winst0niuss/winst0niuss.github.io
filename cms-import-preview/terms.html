The service

The app compares a CSV file you choose with a CMS collection of your site before you import the file. It shows which rows are new, changed, unchanged or have errors, the changed values cell by cell, and problems such as wrong value types, duplicate keys and links to items that do not exist. It can build a safe import file with the new and changed rows. The app only reads your collections; importing a file is done by you in the Wix CMS.

Your files and your data

The results reflect the collection at the time of the check; changes made in the CMS after that are not included. Review the results and the safe file before importing it, and import it as the app describes. The app checks collections and files of up to 50,000 rows.
