Dropbox Folder: File Library privacy policy

Last updated: November 16, 2026

Dropbox Folder: File Library ("the app", "we") is an app for Wix sites that shows the files of a shared Dropbox folder as a file library on site pages. This policy explains what data the app uses and why. By using the app, you agree to this policy.

Data from visitors

  • A file library block loads the list of files (names, sizes and dates) from the app's server on Wix. When a visitor opens or downloads a file or sees an image preview, the app's server fetches that file from Dropbox and passes it to the visitor's browser without storing it.
  • For folders kept for site members, the app checks with Wix that the visitor is logged in as a member of the site. It does not read or store the member's name, email or other profile data.
  • To load faster, the visitor's browser keeps the list of a public folder in its own session storage for up to 5 minutes. Lists of members-only folders are not kept.
  • Search and sorting happen inside the visitor's browser; search words are not sent anywhere. The app does not use cookies, tracking or analytics.

Data from site owners

  • The app stores your folders (title, Dropbox share link, who can see it), look settings and a short-lived copy of the file lists (names, sizes, dates, refreshed every few minutes) in a data collection on the site's own Wix account and not on servers of ours. Only the app's server can read this collection.
  • The app sends your share link to the Dropbox API to read the folder; Dropbox processes these requests under its own privacy policy. The app does not sign in to your Dropbox account and cannot see anything outside the folders you share.
  • The app reads the app plan from Wix to know whether the library should show on the live site, and keeps only whether the plan is active and when it was checked. It also reads whether your site has a member login, to warn you about members-only folders.
  • If you ask Aria about your file libraries, the app returns the folder titles, who can see them and file counts of the current site to Aria inside Wix, without the Dropbox links. Aria can only read, not change anything.

The app does not send emails or notifications. We do not sell data and we do not use it for advertising.

Where data is processed

The app runs on Wix hosting, and its data stays in the site's Wix account. Files are read from Dropbox on request. Wix and Dropbox act as our service providers. If you email us, we use your message and address only to answer you.

Retention, access and deletion

Your folders stay in the app until you change or remove them in the app dashboard; the copy of file lists is replaced every few minutes. Removing the app takes the file library blocks off your pages; Wix may keep or delete the app's data collection under its own rules. To ask a question about your data, email us.
